# Instrucciones del proyecto

## Prioridad inicial del proyecto

Avanzar rapido las primeras fases, pero entendiendo lo importante.

### Fase 1 - Base funcional rapida

Objetivo: que el proyecto Laravel arranque correctamente y tenga estructura clara.

Debe incluir:

- Configuracion inicial del proyecto.
- Base de datos funcionando.
- Rutas principales.
- Layout Blade simple.
- Pagina de inicio.
- Navegacion basica.
- Primer commit.

### Fase 2 - Formularios y usuarios

Objetivo: llegar rapido a un prototipo usable.

Debe incluir:

- Login de usuarios.
- Roles simples: admin, carga, consulta.
- Formularios de prueba para cargar datos ficticios.
- Al menos 2 formularios funcionales.
- Listado de datos cargados.
- Diferencias basicas por rol:
  - admin puede ver todo.
  - carga puede crear registros.
  - consulta solo puede mirar.
- Validaciones basicas.
- Commits separados por parte.

## Documentacion obligatoria

Crear y mantener una carpeta:

```txt
docs/
```

Archivos obligatorios:

- `docs/RUTAS.md`
- `docs/CONTROLADORES.md`
- `docs/FLUJO_PROYECTO.md`
- `docs/ESTRUCTURA_PROYECTO.md`

## Reglas de trabajo

- No hacer todo de una sola vez cuando se planifica.
- Priorizar simplicidad sobre complejidad.
- Mantener arquitectura MVC.
- Explicar que archivos se crean o modifican.
- Sugerir un commit al finalizar cada etapa.
- Mantener el proyecto defendible para una evaluacion de curso.
